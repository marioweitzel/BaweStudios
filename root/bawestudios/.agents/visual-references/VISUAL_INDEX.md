# VISUAL_INDEX.md - BaWe Visual Catalog v1.0

Este catalogo clasifica las 80 capturas existentes por contenido real, patron reutilizable y riesgo. Las capturas son referencias parciales: no son plantillas, no son autoridad de diseno y no sustituyen al Visual DNA.

## Uso En Motor V5

Este indice fue traido desde V4.9 como catalogo de referencias visuales reutilizables.
Antes de seleccionar imagenes, leer tambien:

```text
.agents/visual-references/VISUAL_PATTERN_ADDENDUM.md
```

Regla clave: `filename` y `legacy_filename` no son autoridad visual. La seleccion
debe basarse en `content_type`, `screen_type`, `primary_pattern`, `recommended_for`,
`avoid_for`, `do_not_copy` y los rasgos extraibles del addendum V5.

El LLM debe mirar solo las imagenes candidatas seleccionadas. No debe recorrer las
80 capturas salvo auditoria explicita del motor.

## Reglas De Seleccion

```text
Visual DNA + tipo de feature + contexto de uso + patron requerido
-> referencias candidatas
-> seleccion justificada por el LLM
```

El catalogo propone anatomias, patrones y riesgos. No decide estilo final, navegacion final, layout final, paleta final ni tipografia final.
