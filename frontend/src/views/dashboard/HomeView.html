Bienvenido a BaweStudio

Tu motor inteligente para crear proyectos web con acompañamiento conversacional. Respondé preguntas clave y BaweStudio prepara el contexto para construir tu app.

1. Navegación

Usá el menú lateral para moverte entre Inicio, Nuevo Proyecto y Proyectos. En la franja inferior tenés tu perfil y el cierre de sesión.

2. Nuevo proyecto

Respondé la entrevista de ADN para que BaweStudio prepare el contexto del proyecto y lo deje listo para desarrollo.

3. Proyectos

Revisá el estado de cada proyecto, retomá entrevistas pendientes y accedé a descarga o preview cuando estén disponibles.

¿Tenés un proyecto en mente hoy?
